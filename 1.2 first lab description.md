Grab 2 computers, and a copper straight through cable. (Means ethernet cable.) connect both of them to the switch. configure them like this:

Get two computers, connect both to a switch with copper straight through.
Open each computer. We don't have DHCP configured yet so we'll assign an identity ourselves.
Assign each computer the IP addresses of:
192.168.1.11
192.168.1.12
Why? Because 192.168.1.1 is supposed to ALWAYS be the router. It makes organizing cleaner.
Go to Desktop -> IP Configuration. Subnet Mask is 255.255.255.0 (will go into more detail in a future lab)
The Default Gateway is 192.168.1.1. This means the router. But we don't have a router yet! So don't worry.
DNS server typically is either google 8.8.8.8, 8.8.4.4 or cloudflare which is more private 1.1.1.1, 1.0.0.1. I used 1.1.1.1

Next, switch to simulation mode. The thing at the bottom right. From one computer, go to the "Command Prompt" and type 
ping 192.168.1.12
