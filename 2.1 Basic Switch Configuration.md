Go to the terminal to get access to the switch. Type "enable" to escalate priveledges. Type "configure terminal" to enter global configuration mode. OKAY now to program this stupid thing!

Let's change the name of the switch:

hostname Switch-1

To set the password, do it like this:

enable secret password

The password is just password. But NEVER do "enable password password" always "enable secret password". Replace password with whatever you want the password to be. I left mine as password because... learning...

Now type "exit" to go back to the admin mode. Type "write memory" to save your configuration. Finally "reload" to restart the switch!

Type "show running-config" to see the running commands:

Recap:

Old commands:

(none)

New commands:

**enable**

This command enters administrator mode.

**configure terminal**

This command enters global configuration, the place you usually want to be.

**hostname Switch-1**

This command renames the switch "Switch-1" but you can name it anything.

**enable secret password**

This command sets the password as "password"

(inside admin mode)

**write memory**

this command saves your configuration to boot.

**reload**

this command restarts the switch

**show running-config**

this command shows the commands to configure the switch.
