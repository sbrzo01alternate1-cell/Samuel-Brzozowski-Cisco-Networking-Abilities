From the first lab type *enable* to get admin mode.

get to global configuration mode:

*configure terminal*

Name it:

*hostname Router-1*

Password:

*enable secret password*

save:

*write memory*

restart:

*reload*

Go back to global config mode. Select an interface to configure like this:

**interface GigabitEthernet0/0/0**

Okay, NOW let's assign the IP Address for the default gateway! (Router)

**ip address 192.168.1.1 255.255.255.0**

finally turn the port on like this:

**no shutdown**

Now just save it, going back to the admin mode:

*write memory*

# New commands:

**show ip interface**

This lists the ip interfaces

**interface GigabitEthernet0/0/0**

This goes into an interface to configure it

**ip address 192.168.1.1 255.255.255.0**

This command sets an ip address to a router port.

# Old commands:

**enable**

This command enters administrator mode.

**configure terminal**

This command enters global configuration, the place you usually want to be.

**hostname Switch-1**

This command renames the switch "Switch-1" but you can name it anything.

**enable secret password**

This command sets the password as "password"

(inside admin mode)

**write memory**

this command saves your configuration to boot.

**reload**

this command restarts the switch

**show running-config**

this command shows the commands to configure the switch.
