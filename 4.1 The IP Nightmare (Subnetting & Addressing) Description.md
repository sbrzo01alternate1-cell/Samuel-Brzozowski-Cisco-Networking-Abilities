This is difficult. Normally subnets are just 255.0.0.0, 255.255.0.0, or 255.255.255.0. Here's what that means:

if your IP address is this for example and subnet is this:

ip    :  10.0.0.1

subnet: 255.0.0.0

then these 2 are the same network (10.234.100.1 and 10.0.0.1) but these are DIFFERENT networks (11.0.0.1 and 10.0.0.1) because of that number in the front, corresponds to the 255.0.0.0

Also here's a class B address, similar logic:

ip    : 172. 16.0.1

subnet: 255.255.0.0

172.16.1.1 and 172.16.2.1 are in the same network because they correspond with the 255.255 BUT 172.16.1.1 and 172.17.1.1 are in DIFFERENT networks.

also 192.168.100.1 means class C, and the first 3 numbers are the network portion, last number is the computer portion. corresponds to the subnet 255.255.255.0.

But... this isn't enough. What if we need like 10 computers in a network, or 100? if we need 100, then the last number of 192.168.100.1-255 has 255 addresses total and 155 are WASTED after the 100 computers are used up!

So here we do ADVANCED subnetting. What does that mean? It means we don't have to use the entire 256 addresses, we can split them! How?

First let's talk about class C. The most common addressing block for private networks. 

Our network is 192.168.10.0 and subnet is 255.255.255.0

192.168.10.0 is NOT usable. I honestly have no idea why to this day

192.168.10.1 is usally the router's IP Address

192.168.10.2 - 192.168.10.254 are the main USABLE IP Addresses.

192.168.10.255 is NOT usable, the broadcast ID.

In summary the first address is not usable, the second goes to the router, the last is not usable.

that means 192.168.10.0 and 0+128 = 128 so the last address is 192.168.10.127 and the next network starts at 128. But remember first and last are not usable, and the second is the router.

Okay! Now to configure the routers!

First I clicked the one on the left, typed *show ip interface* again. I went into each one by typing something like: *interface GigabitEthernet0/0/0* and then *no shutdown*

NOW let's add our IP addresses! Since there are multiple "router gateways" we need to have one port have MULTIPLE IP Addresses. How do we do that?

On the left router type these commands to add multiple IP Addresses:

*interface GigabitEthernet0/0/0*

*no shutdown*

*no ip address*

**interface GigabitEthernet0/0/0.10**

**encapsulation dot1Q 10**

*ip address 192.168.10.1 255.255.255.192*

*exit*

**interface GigabitEthernet0/0/0.20**

**encapsulation dot1Q 20**

*ip address 192.168.10.1 255.255.255.192*

*exit*

Great! Finally! Now go back to the switch the router is connected to:

**vlan 10**

This enables the vlan. Must be exactly the same as on the router

**name Development_Team**

Names the vlan. Nothing else. Might not even be necessary.

now do *vlan_20* *name Sales_Team*

Now for the port connected to the router

*interface GigabitEthernet 0/1* (the one connected to the router)

**switchport mode trunk** 

And the interface connected to the other switch do the same.

*Interface GigabitEthernet 0/2*

*switchport mode trunk*

in the other switch, do the same:

*Interface GigabitEthernet 0/1*

*switchport mode trunk*

But as for the interfaces directly connected to a computer:

*interface FastEthernet 0/1*

**switchport mode access**

**switchport access vlan 10**

same for FastEthernet 0/2 and 0/3
