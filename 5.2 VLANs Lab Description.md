5.2 VLANs Lab Description.

In this lab, I will create two VLANs, two computers in each VLAN (four total), and one router and one switch. Names of VLANs will be HR and Engineering. We will use 
VLAN 10 and VLAN 20. 192.168.10.0/24 and 192.168.20.0/24 networks. No subnetting this time.

# Basic Setup:

First get four computers, then one switch, and one router. Plug in the basic IP information. Here's what I got so far. No commands entered yet:

![image](https://github.com/user-attachments/assets/e8cfe4b0-788d-4bd2-9ef1-123297cea609)

Go to the switch. 

**enable**

**configure terminal**

NOW for the vlans!

type these to create a vlan

**vlan 10**

**name HR**

**exit**

**vlan 20**

**name Engineering**

**exit**

<img width="1920" height="1080" alt="Creating VLANs" src="https://github.com/user-attachments/assets/a89eda46-5795-4028-9ca0-af55f5da4a9f" />

Now go to the interfaces and set the vlans:

**interface fastEthernet 0/1**

**switchport mode access**

**switchport access vlan 10**

**exit**

**interface fastEthernet 0/2**

**switchport mode access**

**switchport access vlan 10**

**exit**

That's not working as fast as we want it. Let's make it go faster by configuring multiple ethernet ports at the same time!

**interface range fastEthernet 0/3 - 4**

**switchport mode access**

**switchport access vlan 20**

**exit**

<img width="1920" height="1080" alt="switchports" src="https://github.com/user-attachments/assets/998e2e7e-1e75-4750-aa46-a7c3ac1d61f6" />

Do these commands:

**show run**

**show vlan brief**

<img width="1920" height="1080" alt="show vlan" src="https://github.com/user-attachments/assets/42d616e5-6887-460a-a6f1-4d2dddda30f7" />

Now configure the router command! For the port connected to the router, it's usually a good idea to just do this by default:

**interface gigabitEthernet 0/1**

**switchport mode trunk**

**switchport trunk allowed vlan 10,20**

**no shutdown**

<img width="1920" height="1080" alt="trunk allowed" src="https://github.com/user-attachments/assets/63607bea-e943-4495-921f-dcc11cae43d2" />

Now for the router!

**enable**

**configure terminal**

**interface GigabitEthernet 0/0/0***

**no shutdown**

**exit**

Now we set up the "sub" interfaces for multiple ip addresses!

**interface gigabitEthernet 0/0/0.10**

**encapsulation dot1Q 10**

**ip address 192.168.10.1 255.255.255.0**

**exit**

**interface gigabitEthernet 0/0/0.20**

**encapsulation dot1Q 20**

**ip address 192.168.20.1 255.255.255.0**

**exit**

# Setup VLANs (and subnets):
First on the switch, create the vlans:

**vlan 10**

**name HR**

**exit**

Then on the interfaces enable the vlan you want

**interface range fastEthernet 0/1 - 2**

**switchport mode access**

**switchport access vlan 10**

**exit**

Now on the interface connected to the router:

**interface gigabitEthernet 0/1**

**switchport mode trunk**

**switchport trunk allowed vlan 10,20**

**no shutdown**

NOW on the router itself:

**interface GigabitEthernet 0/0/0***

**no shutdown**

**exit**

Now for the router sub interfaces:

**interface gigabitEthernet 0/0/0.10**

**encapsulation dot1Q 10**

**ip address 192.168.10.1 255.255.255.0**

**exit**

**interface gigabitEthernet 0/0/0.20**

**encapsulation dot1Q 20**

**ip address 192.168.20.1 255.255.255.0**

**exit**
