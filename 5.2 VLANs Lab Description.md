5.2 VLANs Lab Description.

In this lab, I will create two VLANs, two computers in each VLAN (four total), and one router and one switch. Names of VLANs will be HR and Engineering. We will use 
VLAN 10 and VLAN 20. 192.168.10.0/24 and 192.168.20.0/24 networks. No subnetting this time.

# Basic Setup:

First get four computers, then one switch, and one router. Plug in the basic IP information. Here's what I got so far. No commands entered yet:

![image](https://github.com/user-attachments/assets/e8cfe4b0-788d-4bd2-9ef1-123297cea609)

Go to the switch. 

**enable**

**configure terminal**

NOW for the vlans!

type these to create a vlan

**vlan 10**

**name HR**

**exit**

**vlan 20**

**name Engineering**

**exit**
